## 🔍 프로그래머스 SQL - SELECT 파트 학습 내용 요약

| 문제 이름 | 핵심 학습 문법 및 함수 |
| :--- | :--- |
| **12세 이하인 여자 환자 목록 출력하기** | `IFNULL()`: NULL 값을 다른 문자로 대체 |
| **평균 일일 대여 요금 구하기** | `ROUND()`: 반올림 함수 활용 |
| **조건에 맞는 도서 리스트 출력하기** | `DATE_FORMAT()`: 날짜 형식(YYYY-MM-DD) 지정 |
| **흉부외과 또는 일반외과 의사 목록 출력하기** | `IN()`: 여러 값을 OR 조건으로 간결하게 묶기 |
| **3월에 태어난 여성 회원 목록 출력하기** | `IS NOT NULL`: NULL 비교 시 `=` 대신 사용 |
| **조건에 부합하는 중고거래 댓글 조회하기** | `Table Alias`: 조인 시 `테이블명.컬럼명`으로 명시 |
| **재구매가 일어난 상품과 회원 리스트 구하기** | `GROUP BY` & `HAVING`: 그룹화 후 조건 필터링 |
| **상위 n개 레코드** | `LIMIT`: 출력할 행의 개수 제한 |
| **조건에 맞는 회원수 구하기** | `YEAR()`, `BETWEEN`: 날짜에서 연도만 추출 및 범위 지정 |
